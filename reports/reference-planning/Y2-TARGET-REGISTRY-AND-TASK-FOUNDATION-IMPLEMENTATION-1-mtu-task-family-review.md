## Label Resolution

| Label | Resolved meaning |
|---|---|
| `source_value_selection` | select and cite values or source terms from an official source, table, figure, or context |
| `table_value_selection` | select table rows, units, variables, and comparative changes before calculation or explanation |
| `source_chain_builder` | compose a sourced causal or incentive chain where each link is traceable to a source element |
| `calculation_work` | perform arithmetic, formula substitution, expected-value, percentage, or elasticity calculation with units |
| `formula_derivation` | derive a usable expression such as total revenue or marginal revenue from a source formula |
| `sentence_builder` | build a complete economic sentence that includes mechanism and consequence |
| `constructed_response` | produce an open explanation whose correctness depends on a multi-link economic argument |
| `assertion_reason` | pair a claim with a source-backed economic reason |
| `matching_pairs` | map source concepts, strategies, actors, or conditions to their functions |
| `step_ordering` | sequence a reasoning path so the answer form follows the official correction model |
