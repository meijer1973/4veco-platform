## Candidate Status Contract

For each candidate, the row-level source supplies or routes:

- OP-row mapping;
- exam-anchor status;
- target-exercise status;
- MTU/task-family status;
- answer-form requirement;
- blocker;
- production disposition.

This index resolves the remaining count and structural dispositions so later
target packets can use the row-level matrices without reopening blueprint
design.

## Final Dispositions

- `mapping_ready`: structural placement is coherent only.
- `evidence_needed`: official prompt/source/correction, target, or MTU proof
  is missing before production.
- `decomposition_needed`: operation or answer-form decomposition is needed
  before storage/production.
- `deferred`: bridge/practice/retrieval item is not a count-bearing paragraph
  target in the current model.

No candidate has unknown maturity status.
