## Goal

break-even. Use the root golden textbook package as the source content, place

proof must include paragraph/chapter validators, rendered output, result
evidence, command evidence, lead review, and named follow-up records for any

## Operationalized sprint procedure

1. Record baseline from the current integrated 2.1.2 and the root golden package.
2. Import only the 2.1.2 package into the canonical paragraph folder with canonical filenames. Stop if the import would require editing 2.1.3 or target source records.
3. Rebuild 2.1.2 rendered output through `build_pdf.py`; rebuild Chapter 2.1 through `build_chapter.py`.
4. Run paragraph, chapter, book, roadmap, scope-language, and sprint validators. Stop for correction if any validator fails.
5. Prepare import notes, result, diff summary, result JSON, and lead-review assignment.
6. Send the bundle to the lead review agent, apply required corrections or record that none were needed, and request round 2.
7. Run complete-bundle validation before marking the sprint complete.
