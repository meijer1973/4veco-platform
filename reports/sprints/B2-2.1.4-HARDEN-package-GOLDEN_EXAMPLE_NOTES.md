# Golden example notes - 2.1.4 mixed exercises

This package is meant as a pattern for future `gemengde opgaven` paragraphs.

## What agents should copy

1. Start by saying that no new theory is introduced.
2. Build the paragraph around source reading and operation choice.
3. Give a visible route from source to formulas, totals, averages, graph, and marginal reasoning.
4. Keep the formula card limited to prior theory.
5. Use a doeloefening that combines earlier skills in one realistic context.
6. In the answer model, end each substantial calculation with an economic sentence.

## What agents should not copy blindly

1. Do not invent new concepts in a mixed paragraph.
2. Do not use the mixed paragraph to sneak in the next chapter's theory.
3. Do not claim reviewed-final status when the upstream registry still has a placeholder target.
4. Do not make graph tasks decorative. The graph must support an operation: break-even, profit/loss zone, or vertical profit distance.
5. Do not calculate marginal values from a single row. Use two consecutive rows.

## Specific golden-example move

The local target exercise has two sources. Source 1 supports normal formulas and break-even. Source 2 changes the task into marginal table reasoning. This is the right shape for mixed practice: students must identify which earlier procedure each source calls for.
