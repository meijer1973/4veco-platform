## Consolidation Shape Decision

Book 1 mixed-practice paragraphs and the current validators define
`gemengde_opgaven` as a consolidation shape: official Part A print output is
`opgaven` plus `antwoorden`, with no `paragraaf` file and no new theory.

The package paragraaf material is therefore treated as source/strategy
evidence only, not as an official theory paragraph. The canonical 2.1.4 folder
contains only the official consolidation source files.

## Asset Decision

The package contained figure assets named `2.1.4_fig_1`, `2.1.4_fig_2`, and
`2.1.4_fig_3`, but the official canonical `opgaven.md` and `antwoorden.md` do
not reference them. Keeping those files in `_assets/` produced orphaned-asset
warnings without affecting rendered output.

The unreferenced 2.1.4 figure assets were removed from both the paragraph
`_assets/` folder and the Chapter 2.1 aggregate `_assets/` folder. The official
2.1.4 consolidation paragraph now validates with `_assets/: 0 SVGs, 0 PNGs`.
