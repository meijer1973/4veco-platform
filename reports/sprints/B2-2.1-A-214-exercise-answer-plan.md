## Opgave Draft

### Opgave 1: Bakkerij De Morgen

Bakkerij De Morgen wil beslissen of zij op zaterdag meer broden moet bakken.
De vaste kosten zijn EUR 600 per week. Voor de eerste 800 broden zijn de
variabele kosten EUR 1,10 per brood. Boven 800 broden moet de bakker overuren
betalen. Daardoor zijn de variabele kosten voor elk extra brood boven 800
broden EUR 1,40. De verkoopprijs is EUR 2,00 per brood.

Gebruik `Q` voor het aantal broden per week.

**1** *(3p)* Schrijf voor `Q <= 800` de formules voor `TCK`, `TVK` en `TK`.
Bereken daarna `TK`, `GTK`, `GCK` en `GVK` bij `Q = 400` en `Q = 800`.

**2** *(2p)* Schrijf de formule voor `TO`. Bereken `TO` en `winst` bij
`Q = 400` en `Q = 800`.

**3** *(2p)* Bereken bij welke productieomvang de bakkerij quitte speelt,
zolang `Q <= 800`. Leg uit wat dit punt betekent.

**4** *(3p)* Teken voor `Q = 0` tot en met `Q = 800` een grafiek met `TK` en
`TO`. Zet het break-evenpunt in de grafiek en geef aan bij welke hoeveelheden
de bakkerij winst maakt.

**5** *(3p)* Vul de tabel aan.

| Q | TK | TO | winst | MK | MO |
|---:|---:|---:|---:|---:|---:|
| 700 |  |  |  | - | - |
| 800 |  |  |  |  |  |
| 900 |  |  |  |  |  |
| 1000 |  |  |  |  |  |

Gebruik voor `MK` en `MO` steeds de verandering per extra brood tussen twee
opeenvolgende rijen.

**6** *(2p)* Leg uit waarom `MK` na 800 broden verandert, terwijl `MO` gelijk
blijft. Gebruik de tabel om te beoordelen of produceren van 800 naar 900
broden de winst verhoogt.

### Opgave 2: Festivaldrukte

Door een festival verwacht de bakkerij op zaterdag extra klanten. De bakker
denkt daarom aan een verkoopactie: drie broden voor EUR 5,40. De gemiddelde
verkoopprijs wordt dan EUR 1,80 per brood. De kosten blijven zoals in opgave 1.

**7** *(2p)* Leg uit wat er met `TO` gebeurt als de gemiddelde verkoopprijs
daalt van EUR 2,00 naar EUR 1,80 per brood. Gebruik de formule voor `TO` in je
antwoord.

**8** *(3p)* Onderzoek het break-evenpunt bij een verkoopprijs van EUR 1,80.
Begin met de kostenformule voor `Q <= 800` en controleer of je uitkomst binnen
dat gebied valt. Ligt de uitkomst boven 800 broden? Gebruik dan de kostenregel
voor extra broden boven 800. Vergelijk je eindantwoord met vraag 3.

**9** *(2p)* De bakker zegt: "Door de actie verkoop ik meer broden, dus mijn
winst stijgt zeker." Beoordeel deze uitspraak met behulp van `MO`, `MK` en het
nieuwe break-evenpunt.

## Answer Model Draft

### Antwoord 1

Voor `Q <= 800`:

- `TCK = 600`
- `TVK = 1,10Q`
- `TK = 600 + 1,10Q`

Bij `Q = 400`:

- `TVK = 1,10 x 400 = 440`
- `TK = 600 + 440 = 1040`
- `GTK = 1040 / 400 = 2,60`
- `GCK = 600 / 400 = 1,50`
- `GVK = 440 / 400 = 1,10`

Bij `Q = 800`:

- `TVK = 1,10 x 800 = 880`
- `TK = 600 + 880 = 1480`
- `GTK = 1480 / 800 = 1,85`
- `GCK = 600 / 800 = 0,75`
- `GVK = 880 / 800 = 1,10`

Point guidance: 1 point for correct formulas, 1 point for `Q = 400`, 1 point
for `Q = 800`.

### Antwoord 2

`TO = P x Q = 2,00Q`.

Bij `Q = 400`:

- `TO = 2,00 x 400 = 800`
- `winst = TO - TK = 800 - 1040 = -240`

Bij `Q = 800`:

- `TO = 2,00 x 800 = 1600`
- `winst = TO - TK = 1600 - 1480 = 120`

Point guidance: 1 point for `TO`, 1 point for both profit calculations.

### Antwoord 3

Break-even betekent `TO = TK`.

`2,00Q = 600 + 1,10Q`

`0,90Q = 600`

`Q = 666,67`

De bakkerij speelt dus quitte bij ongeveer **667 broden per week**. Op dat punt
is `winst = 0`: de totale opbrengsten zijn precies gelijk aan de totale kosten.

Point guidance: 1 point for the equation, 1 point for interpretation.

### Antwoord 4

The graph must show:

- horizontal axis: `Q` from 0 to 800;
- vertical axis: money in EUR;
- `TK` starts at EUR 600 and rises linearly to EUR 1480 at `Q = 800`;
- `TO` starts at EUR 0 and rises linearly to EUR 1600 at `Q = 800`;
- break-even point at about `(667; 1333)`;
- profit zone for `Q > 667`, because then `TO > TK`.

Point guidance: 1 point for correct `TK` and `TO` lines, 1 point for the
break-even point, 1 point for correct profit-zone interpretation.

### Antwoord 5

For `Q > 800`:

`TK = 600 + 1,10 x 800 + 1,40 x (Q - 800)`

| Q | TK | TO | winst | MK | MO |
|---:|---:|---:|---:|---:|---:|
| 700 | 1370 | 1400 | 30 | - | - |
| 800 | 1480 | 1600 | 120 | 1,10 | 2,00 |
| 900 | 1620 | 1800 | 180 | 1,40 | 2,00 |
| 1000 | 1760 | 2000 | 240 | 1,40 | 2,00 |

Point guidance: 1 point for correct `TK` values, 1 point for correct `TO` and
profit values, 1 point for correct `MK` and `MO`.

### Antwoord 6

`MK` changes after 800 loaves because each extra loaf above 800 costs more to
produce: the variable cost per extra loaf rises from EUR 1,10 to EUR 1,40.

`MO` stays equal to EUR 2,00 because the selling price stays EUR 2,00 per loaf.
Each extra loaf sold therefore adds EUR 2,00 to `TO`.

Producing from 800 to 900 loaves increases profit. In the table, profit rises
from EUR 120 to EUR 180. The increase is EUR 60, because each of the 100 extra
loaves adds `MO - MK = 2,00 - 1,40 = 0,60` profit.

Point guidance: 1 point for explaining changing `MK`, 1 point for explaining
constant `MO`, 1 point for the profit advice using the table.

### Antwoord 7

Bij een verkoopprijs van EUR 2,00 geldt `TO = 2,00Q`. Bij een verkoopprijs van
EUR 1,80 geldt `TO = 1,80Q`.

Bij dezelfde hoeveelheid is `TO` dus lager. Per verkocht brood ontvangt de
bakkerij EUR 0,20 minder opbrengst.

Point guidance: 1 point for the new formula, 1 point for interpretation.

### Antwoord 8

Begin met de formule voor `Q <= 800`:

`1,80Q = 600 + 1,10Q`

`0,70Q = 600`

`Q = 857,14`

Deze uitkomst ligt boven 800 broden. De formule voor `Q <= 800` is daar dus
niet geldig.

Voor `Q > 800` geldt:

`TK = 600 + 1,10 x 800 + 1,40 x (Q - 800)`

`TK = 600 + 880 + 1,40Q - 1120`

`TK = 360 + 1,40Q`

Break-even:

`1,80Q = 360 + 1,40Q`

`0,40Q = 360`

`Q = 900`

Het geldige break-evenpunt bij de actieprijs is dus **900 broden**. Dat is
hoger dan bij EUR 2,00, waar het break-evenpunt ongeveer 667 broden was.

Point guidance: 1 point for the first candidate and domain check, 1 point for
the piecewise cost formula above 800, 1 point for `Q = 900` and comparison.

### Antwoord 9

Meer verkopen verhoogt de winst alleen als de extra opbrengst van extra broden
groter is dan de extra kosten.

Door de actie daalt `MO` naar EUR 1,80 per brood. Tot 800 broden is `MK`
EUR 1,10, en boven 800 broden is `MK` EUR 1,40. Extra productie kan dus winst
toevoegen, maar de bakker moet wel het hogere break-evenpunt van 900 broden
halen. Meer afzet alleen is geen bewijs dat de winst stijgt, omdat de actie ook
de opbrengst per brood verlaagt.

Point guidance: 1 point for the distinction between more sales and more profit,
1 point for using `MO`, `MK`, or break-even in the assessment.
