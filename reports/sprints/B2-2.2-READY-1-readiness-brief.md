## Elasticity Notation And Sign Contract

| Concept | Contract |
|---|---|
| Percentage change | Use `(new - old) / old x 100%` unless the source explicitly gives the percentage change. Name the old value as the denominator. |
| Price elasticity of demand | Use `Ev = %dQv / %dP`. For a normal downward-sloping demand relation, a price increase and quantity decrease gives a negative `Ev`. |
| Classification of price elasticity | Report the signed value first, then classify with `|Ev|`: `|Ev| > 1` elastic, `|Ev| < 1` inelastic, `|Ev| = 1` unit elastic. |
| Language for negative `Ev` | Do not hide the sign. If a task or source uses positive-only elasticity, the answer must say it is using the absolute value for classification. |
| Income elasticity | Use `Ei = %dQv / %dY`. `Ei > 0` means normal good; `Ei < 0` means inferior good. For normal goods, `0 < Ei < 1` is necessity and `Ei > 1` is luxury. |
| Cross elasticity | Use `Ek = %dQv of good A / %dP of good B`. `Ek > 0` means substitutes; `Ek < 0` means complements. |
| Units | Elasticities have no unit. Calculations still show percent changes and relevant source units such as euros, tickets, litres, or quantity. |
| Rounding | Keep enough intermediate precision to avoid changing the classification. Round final elasticities consistently, usually to two decimals unless the task says otherwise. |

## Graph And Table Contract

| Surface | Contract |
|---|---|
| Demand graph | Horizontal axis is quantity `Q` or `Qv`; vertical axis is price `P`. Old and new points must be labelled directly. Movement along demand is not a demand shift unless the source explicitly changes a non-price determinant. |
| Before/after table | Tables must show old and new `P`, `Qv`, percentage changes, and optionally `TO`. The denominator for each percentage change must be recoverable from the table or answer. |
| Omzet rectangle | Revenue rectangles may be used in 2.2.2 only if the graph remains readable and the answer links area to `TO = P x Q`. |
| Demand-function table | For 2.2.3, show which variables are held constant. A table should separate original value, changed value, resulting `Qx`, percentage change, and classification. |
| Figure source preflight | Any changed graph or figure in later output sprints must have stable filenames, SVG/PNG pairing, regenerated pairs, readable labels, non-color-only meaning, and graph/text concordance under `references/authored/textbook-figure-standard.md`. |
| Rendered proof | Final acceptance of graphs and tables happens on the rendered page under `references/authored/textbook-rendered-page-acceptance-standard.md`. Source checks are not enough. |

## Misconception List

| Misconception | Required prevention in later paragraph work |
|---|---|
| Percentage points treated as percent change. | Ask students to compute `(new - old) / old x 100%` and identify the denominator. |
| New value used as denominator by default. | Answer models must name the old value as base unless the source gives another convention. |
| Negative `Ev` dropped without explanation. | Show signed `Ev` and then classify using `|Ev|`. |
| Elastic/inelastic classification based on sign. | State that size uses `|Ev|`; sign describes direction. |
| "Inelastic" understood as no quantity change. | Say quantity still changes, but proportionally less than price. |
| Omzet confused with profit. | Keep 2.2.2 advice tied to `TO = P x Q`; do not introduce costs or profit unless the task explicitly supplies them. |
| `Ei` luxury/necessity classification applied to inferior goods with `|Ei|`. | Use signed `Ei`: inferior if negative; necessity/luxury only for positive normal goods. |
| `Ek` denominator uses the price of the same good. | Name the affected demand good and the changed other-good price. |
| Demand function variables all changed at once. | Mark ceteris paribus: only one driver changes unless the question explicitly changes more. |
| Graph movement confused with demand shift. | Label points and explain whether the source changes price or another determinant. |

## Answer-Model Route

| Question type | Required answer structure |
|---|---|
| Calculation | Formula -> identify old/new values -> percentage changes -> substitution -> signed result -> rounded result -> classification/conclusion. |
| Table interpretation | Identify old and new row -> compute relevant changes -> compare proportional changes -> state economic meaning. |
| Graph interpretation | Read labelled point/line/area -> extract values -> compare old/new state -> explain the elasticity or omzet meaning. |
| Explanation/advice | Position -> because calculation or source evidence -> economic meaning -> bounded advice. |
| Mixed-source question | Select relevant source data -> choose formula family -> calculate or interpret -> connect to the business or consumer context. |
