## Result

The trusted bundle refresh now distinguishes the four canonical
generated-and-verified agent indexes from the actual runtime commit delta. A
new or reused refresh commit may change a unique, non-empty subset of those
paths, while trusted platform-main code still regenerates twice,
freshness-checks, validates canonical metadata, hashes, and byte-verifies all
four files.

Creation verifies the exact one-parent commit shape and actual subset, proves
the committed blobs match the canonical generated bytes and returned hashes,
then repeats those checks after a non-force push and refetch. Reuse regenerates
all four files from the candidate parent and compares the complete candidate
tree. Dry-run reports only what would be verified and cannot satisfy a
completed refresh proof.

The integration contract and readiness attestation are schema v2. The
attestation digest binds both actual changed paths and all verified paths, and
the refresh proof cross-checks the commit SHA, parent, and changed paths.
Post-lead changed paths remain GitHub-compare-derived; supplemental lead-review
claims cannot replace them.

## Concrete Recovery Regression

The regression first creates the prior canonical lesson refresh, then adds a
non-index repaired-platform-main descendant. The next trusted refresh changes
exactly the two platform index files, verifies and hashes all four canonical
files, pushes the one-parent tail, and reuses that exact tail idempotently on a
retry.

## Fail-Closed Coverage

- commit-time mutation of an allowlisted index file before push;
- empty refresh commit;
- correct index subset attached to the wrong parent;
- stale or tampered reusable descendant;
- unexpected generator output and nondeterministic generation;
- rejected push and mismatched refetch head;
- empty, duplicate, outside, or mismatched changed-path proof;
- incomplete verified-path proof;
- legacy schema-v1 contract or readiness attestation;
- changed-path or verified-path mutation under a stale v2 attestation digest;
- supplemental post-lead path substitution.
