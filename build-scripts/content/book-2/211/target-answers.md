b) {{ANSWER_b}}

Je bouwt de functies zo op:

- TCK = 440 + 60 = **500**.
- De variabele kosten per brood zijn 0,70 + 0,10 = **€ 0,80 per brood**.
  Vermenigvuldig met Q: TVK = **0,80Q**.
- TK = TCK + TVK = **500 + 0,80Q**.

c) {{ANSWER_c}}

De tellers komen uit de totale kosten bij Q = 500:
TCK = € 500, TVK = 0,80 × 500 = € 400 en TK = 500 + 400 = € 900 per maand.
Je deelt ieder totaal door dezelfde 500 broden van die maand.

d) {{ANSWER_d}}

Bij Q = 1.000 zijn TCK = € 500, TVK = 0,80 × 1.000 = € 800 en
TK = 500 + 800 = € 1.300 per maand. De volledige berekeningen zijn:

- GCK = TCK/Q = 500/1.000 = **€ 0,50 per brood**.
- GVK = TVK/Q = 800/1.000 = **€ 0,80 per brood**.
- GTK = TK/Q = 1.300/1.000 = **€ 1,30 per brood**.
