# Presentation Policy

Status: production policy namespace for web-first and PowerPoint-derivative presentation work.

This folder defines reusable presentation standards extracted from `references/exemplars/1.1.1-golden-presentation/`.

Use this folder for:

- web-first presentation route policy;
- semantic model requirements;
- student-facing speaker notes;
- renderer and layout requirements;
- PowerPoint derivative guidance;
- review and validation expectations.

Do not use this folder to authorize product use, Scale Gate 1, diagnostics, mastery, automatic sequencing, summative use, target-equivalent completion claims, broad migration, or hand-edited generated lesson output.

## Files

- `presentation-policy.md` / `presentation-policy.json` - top-level policy and machine-readable contract.
- `web-first-presentation-layout.md` / `web-first-presentation-layout.json` - web surface layout requirements.
- `speaker-notes-policy.md` / `speaker-notes-policy.json` - structured student-facing notes requirements.
- `didactic-route-policy.md` / `didactic-route-policy.json` - default economics presentation route and slide-role contract.
- `powerpoint-derivative-policy.md` - PPTX export guidance after web review.

## Key Distinctions

- A conceptual exemplar explains the product standard.
- An implemented exemplar proves the repository can generate and validate the surface.
- A web-first presentation is the design source.
- A generated web artifact is student-facing output regenerated from platform source.
- A PowerPoint deck is a derivative export, not the design source when a web route exists.
