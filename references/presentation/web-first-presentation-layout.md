# Web-First Presentation Layout

Status: renderer and layout policy for web-first presentations.

## Required Page Affordances

The page must include:

- sidebar or slide-list navigation;
- slide count or progress indicator;
- keyboard navigation;
- notes toggle;
- dark mode;
- fullscreen or presentation mode if available;
- clear return route;
- semantic headings;
- accessible buttons and labels.

## Slide Layout Rules

- Show one learning move at a time.
- Keep the assertion visible and easy to scan.
- Put procedures on the slide surface, not only in notes.
- Keep student-facing notes readable as a first-class panel.
- Preserve mobile usability without clipped text, clipped controls, or horizontal overflow.
- Preserve dark-mode contrast for text, diagrams, tables, and notes.

## Required Layout Families

Production renderers should support:

- route contract cards;
- narrative case comparisons;
- relation diagrams;
- transfer cards;
- misconception comparison cards;
- procedure steps;
- worked-example tables;
- worked-example interpretation panels;
- retrieval/check cards;
- summary and bridge layouts.

## No PowerPoint-First Assumption

The web artifact must not require a PowerPoint download button. A PPTX link may appear only when a reviewed derivative export exists.
