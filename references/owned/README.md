# Owned Reference Sources

This folder contains source material created by the platform team.

Owned sources are stronger than ordinary planning notes because they express the course design, but they are not outside authority and they are not machine registries.

Use owned sources for:

- course design and paragraph sequencing
- target-exercise alignment
- lesson/source retrieval
- projection edges into the content graph

Do not use owned prose alone to mint machine units. New units still require exercise-first evidence, preferably real exam questions or explicit target exercises.

Current owned sources:

- `course-blueprint-v6-three-year.md` - owned 11-book, three-year umbrella planning authority. It embeds v5 as the detailed Year 1 / Books 1-4 baseline and reconciles the older three-year concept to the 4 + 4 + 3 formal test-week model. It is not authority for protected mutation, Year 2/3 paragraph targets, lesson output, product-route adoption, Scale Gate, diagnostics, mastery, PV, summative use, or student/product use.
- `course-blueprint-v6-three-year.meta.json` - metadata and authority constraints for the promoted v6 three-year umbrella blueprint.
- `course-blueprint-v5.md` - active v5 curriculum-source scaffold for the 12/12/14/16 four-test-week model.
- `course-blueprint-v5.meta.json` - metadata and authority constraints for the active v5 blueprint.
- `course-blueprint-pedagogical-boundaries.md` - normative interpretation shared by v5 and the Year 1 detail embedded in v6. It distinguishes terminal targets, anticipatory scaffolding/previews, and prerequisite mastery; records the Book 1 first-edition freeze and Book 2 first-edition handoff; and makes no change to counts, book roles, target records, or assessment structure.
- `course-blueprint-v4.md` - superseded v4 blueprint retained for historical comparison and migration traceability.
- `course-blueprint-v4.meta.json` - superseded v4 metadata retained for historical comparison and migration traceability.
