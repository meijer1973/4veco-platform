# 1.1.3 Exit-Ticket Exemplar

Status: implementation candidate only.
Next state: `hold_for_exemplar_review`.

This folder preserves the `1.1.3 Grafieken en tabellen` exit-ticket candidate from `knowledge/113-excellent-exit-ticket-v3-package.zip`.

## What It Is

The candidate is a product-excellence exemplar for a target-equivalent exit ticket that asks the student to perform the actual graph/table operation:

1. choose P-Q axes;
2. place two distinct table points;
3. confirm the line shape;
4. choose the interval before reading a graph value;
5. build the percentage-change formula;
6. calculate and state the decrease conclusion.

It intentionally does not provide pre-attempt procedure steps, static formula context, diagnostic language, mastery claims, score language, or completion-language authority.
