# Quality brief — §1.1.2 Indexcheck

## Why this is a reasoning game

The arithmetic is deliberately simple. The challenge is deciding what the numbers mean and what should serve as the reference value.

The source creates a useful consistency check:

- prices: €60 to €63;
- indices: 120 to 126.

Both valid routes must produce 5%. This makes the reasoning inspectable rather than merely procedural.

## Why this is a real transfer from §1.1.1

The visual language and interaction standards remain familiar, but the task model changes:

- §1.1.1 asks which scarce choice and best alternative matter;
- §1.1.2 asks which unit and comparison base matter.

This demonstrates the correct use of a golden exemplar: retain quality and affordance, rebuild the economics.

## Excellence criteria

An excellent implementation:

- is understandable without a tutorial;
- uses no more than three coherent tasks;
- never moves cards after selection;
- accepts local repair;
- shows meaningful misconceptions as distractors;
- keeps index points and percentages linguistically distinct;
- assembles an exam-usable final answer;
- provides rendered interaction-state proof;
- is reusable without hard-coding this one source.
