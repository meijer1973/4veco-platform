# Adaptation notes — from reasoning-flow to §1.1.1 choice compass

## Transfer lesson

Do not copy the surface form of a golden exemplar. Copy the product reasoning:

- clear source;
- one coherent loop;
- visible reasoning structure;
- low-friction controls;
- plausible misconceptions;
- feedback after attempt.

For a price-mechanism paragraph, a flowchart is often natural. For §1.1.1, a choice/evidence compass is more natural.

## What changed from the earlier reasoning-flow exemplar

- Flowchart chain removed from Task 1.
- Task 1 is now order-free evidence selection.
- Task 2 is a single opportunity-cost decision.
- Task 3 is a compact answer-fragment builder.
- Connectors are not the main target here.
- The game no longer uses a long causal chain.

## What stayed the same

- source-left / task-right layout;
- no answer-giving role tags;
- no mode overload;
- one cognitive operation per task;
- interaction-state proof required;
- negative fixtures required;
- lead review must inspect rendered output, not only contracts.
