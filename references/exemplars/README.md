# Golden Exemplars

This folder stores golden examples that can be used as source artifacts for future implementation work.

## Available Exemplars

- `1.1.3-exit-ticket/` - Golden exit-ticket example for `1.1.3 Grafieken en tabellen`.
- `a96-answer-form/` - Golden answer-form example for A96-style calculation/formula work.

Each exemplar folder keeps its prototype, candidate data, handoff notes, and quality guidance together at one shallow path.
